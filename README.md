## Run instructions

Python examples generally require Python 3. Some machine-learning experiments use scikit-learn and NumPy: `python -m pip install scikit-learn numpy`. From a numbered folder, run `python solution.py`. EXP 31 is an HTML page; open `index.html` in a browser. Prolog examples require SWI-Prolog; run `swipl -q -s <file>`. Sample outputs are illustrative transcripts and may vary by library version.
